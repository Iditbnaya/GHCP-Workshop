# Workshop Output

Copilot creates participant analysis deliverables in this folder during the
labs:

| Lab | File | Purpose |
|---|---|---|
| 2-3 | `reverse-engineering-report.md` | Current-state evidence, rules, calculation trace, questions, and verified diagrams |
| 5 | `user-story.md` | Traceable SR-03 user story and acceptance criteria |
| 7 | `figma-product-coverage-initial.md` | Initial design coverage of product requests and the user story |
| 7 | `figma-coverage-initial.md` | Initial design coverage of organizational requirements |
| 7 | `figma-revision-prompt.md` | Requirement-linked instructions for the revised design |
| 7 | `figma-coverage-revised.md` | Verification of the revised design |

The optional PRD exercise in Lab 6 also creates `prd-draft.md`.

Generated content is a draft. Verify every rule, calculation, diagram element,
and requirement against a cited source before using it.
