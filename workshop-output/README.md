# Workshop Outputs

Students create these files during the labs:

| Lab | File | Maximum size |
|---|---|---|
| 2-3 | `product-snapshot.md` | Seven short sections |
| 4 | `user-story.md` | One story and three acceptance criteria |
| 6 | `design-check.md` | Six checklist rows and three recommendations |

Short limits are intentional. The goal is a useful, reviewable analyst
deliverable - not a complete technical specification.
