# GitHub Copilot System Analysis

A friendly, 95-minute workshop for system analysts using GitHub Copilot for the
first time. Students follow a relatable travel-insurance quote from current
behavior to a clear product snapshot, verified user story, reusable prompt,
and requirements-based design check.

No terminal commands, package installation, or application execution are
required.

## Workshop website

The student website is available at:

https://iditbnaya.github.io/GHCP-Workshop/

GitHub Pages is deployed from `main` by `.github/workflows/pages.yml`.

## Start here

1. Follow [SETUP.md](SETUP.md).
2. Open [WORKSHOP.md](WORKSHOP.md).
3. Create the short repository instruction file.
4. Complete the six labs in order.

## What makes the workshop easy to follow

- A five-minute guided start followed by six connected labs.
- Two small source files and one simple ₪126 example.
- One clear outcome per lab.
- Copy-ready prompts with strict output limits.
- No required MCP or Figma setup.
- Optional Figma practice for participants who already have approved access.
