# Travel Quote Screen Checklist

Use this small checklist to review the proposed screen.

| ID | Expected design evidence |
|---|---|
| DES-01 | The screen clearly identifies travel insurance and its purpose. |
| DES-02 | The traveler can see inputs for destination, dates, and traveler ages. |
| DES-03 | The screen displays one total premium and explains what the price represents. |
| DES-04 | Adventure-sports coverage is available as an optional choice. |
| DES-05 | Validation problems are explained without suggesting that entered data is lost. |
| DES-06 | A clear action lets the traveler continue toward purchase. |

Use only these statuses: `Covered`, `Partial`, `Missing`, or
`Cannot determine from this screen`.
